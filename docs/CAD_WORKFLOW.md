# 原图读取与坐标工作流

## 当前状态

2026-10-05：DWG原件5,715,930 bytes、头部AC1018、SHA保持原值。本机已安装AutoCAD 2026成功将副本导出为`outputs/drawings/factory_converted.dxf`。已盘点82,383顶层实体、188图层、667块及Model/布局1/布局2；文字和尺寸记录可查。未识别外参标志块，不代表全部依赖已获确认。

8F候选图身写“八层平面图”（F0FBF），同框图签写“三层平面图”（F10B1）。INSUNITS=1、MEASUREMENT=0，物理单位仍待工程确认。横向8700（F112C）、纵向6000（F1112）的投影数值一致性有记录，但不是现场尺寸签核。原生-PLOT退出254，未产生原生PDF；缺多种中文/SHX字体。8F部分SVG预览保留坐标关系、转换记录和缺失实体说明，只供来源核查，不能测量或施工。P02/P05保持blocked，实际点位数组为空。

## P01 — 本地读取

先检查用户本地已有AutoCAD/兼容CAD/ODA File Converter。使用已有授权工具、转换副本，不更改inputs，不上传外部转换网站。脚本支持通过ezdxf调用已安装ODA；若无转换器，报告明确安装/导出阻塞。不要反复用LLM“猜DWG”。

输出：DXF副本、每层或每图框PDF、转换日志、图纸盘点JSON。记录Model及各Layout，不假设一个Layout等于一层；如果所有楼层在Model同一大图中，先登记图框世界坐标窗口，再做分层导出。

登记：图纸标题、日期/版次、单位、图层开关、文字样式、SHX/大字体、XREF与光栅依赖、代理对象。缺失依赖不是“空场地”，需停留在缺件状态。原生CAD/PDF用于视觉比对；ezdxf渲染不能保证所有实体和字体完全一致。

## P02 — 楼层与比例

用图纸上的楼层标题确定身份，并与原方案基线对照。冲突列入`docs/DECISIONS.md`，不覆盖任一来源。

在两处不同方向的已知标注尺寸上核验几何长度；记录CAD单位、换算mm的倍数、两点坐标、原标注、计算误差及核验人。不要把一张截图的像素或者打印1:100直接当模型世界单位。

每层保留：source_drawing_sha256、Layout名/图框窗口、world_to_svg可逆矩阵、单位、原点、旋转、裁切边界和校核证据。展示图Y轴与CAD世界Y轴可能方向相反；平移、缩放、旋转必须可追踪。

## P05 — 点位提案

在校核底图上用独立叠加层标点，不擦除原图。每一点至少记录：point_id、floor_id、area_id、template_code、template_revision、source_drawing_sha256、CAD世界XY、朝向、安装方式、尺寸来源、实物数量、双面数、负责人、理由、原图实体/截图证据、状态。

无需先确定安装高度即可表达提案位置，但未知高度必须为null并阻止施工放行。门扇、电梯前室、疏散、消防、设备检修、叉车转弯、货物高度及吊挂载荷均作为专项核查，不自行给出“已满足”结论。

## 导出层建议（提案）

`BP_BASE_REF`只读底图；`BP_ID_PROPOSED`导视提案；`BP_OPS_PROPOSED`运营标识提案；`BP_REVIEW_CLOUD`待确认云线；`BP_NOTES`说明。消防/疏散原图层不编辑。不采用品牌橙作地面施工颜色。

## 人工交接

图纸解析成功≠现场一致；现场一致≠安装获批；安装获批≠所有专项放行。各状态独立登记。需要CAD本机另导出时优先请求原比例矢量PDF和DXF，并保留图框、轴网、尺寸及依赖，不只收低分辨率截图。
