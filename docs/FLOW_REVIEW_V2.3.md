# V2.3 物流与人的动线深化

这轮把既有标牌、相对安装面和效果图推进到交接与运行关系。新增内容不生成实际CAD点位，也不证明现场路线已获批准。

- 14个物流交接接口：前提、工单选路、记录、责任角色、模板与待测事实。
- 5类人员功能路线：员工、补料、品质、工程、访客。品质按任务选支。
- 10类人货交叉核查：先核空间分离、自然路径、视线、停留与接手条件，再评审必须共享时的明确窗口。
- 4张可编辑功能SVG：全厂拓扑、8F泳道、共享运输交接、分类回流。
- 12项邻接/分离建议、7组读面/更新规则；编号不等于现场件数。
- 6款模板变体：WH-05、WH-03、FL-02、WH-04、WF-03、VT-01。名义尺寸复用V1，原件保留，容量/方向/楼层/审批待填。
- 9个功能演练情境、4阶段证据门槛、现场字段及两份只含表头的记录表。
- 30页A3 PDF、离线审阅页与输入为空的补料假设计算器。

工单可选择入5F存储、允许直送4F/8F或适用时进出9F专项接口。来料按检验计划送批/送样，放行外购物料按BOM到实际储位/供料，不强制先经金工/注塑。全部机型不统一套老化。

补料统一口径：δ为达到触发条件到请求建立；L为请求建立到物料在供料点可用（含必要入位），两段不重叠。库存位置排除不可支配预留、冻结和不合格，欠供只扣一次。计算结果须与核定接收容量及共享资源条件复核；没有核定等候位就不把门前或前室当缓存。

V2.2的三张概念效果图保留。新页用其中管理墙和库位图帮助对应读面与交接规则，未把生成图当建筑现状、箱数或安装批准。品牌橙色仅用于牌面，不作橙色地面线；质量状态色保持原语义，不表示交通优先。

仍需确认：有效图框8F/3F冲突、物理单位、现场楼层用途；主要运输工具与设施权限/服务层；逐物料需求及实际接收量；自然人行路径、载具外形、视线和获准等待面；访客范围、正式Logo与1:1可读性；内容、位置、安装及适用专项证据。

本地复建：`python3 scripts/build_flow_review.py`生成功能图及HTML；PDF由已安装Chrome后台打印，PDFKit逐页渲染。图册审阅不是现场验收；未知值保持空，实际点位文件不变。
