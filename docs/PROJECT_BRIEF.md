# 项目任务书

## 目标

把“客户能理解、员工能操作、管理者能发现异常”的BeePump黑橙工厂视觉系统，落实到真实楼层平面和可计量的标识点位。交付物仍是Manual、SVG、点位图、工程量和打样/安装说明；本地预览界面只是评审工具。

## 已有资料与事实层级

1. 原DWG：`inputs/cad/新厂房平面图（改）.dwg`。用户说明这是每层图纸；当前只确认文件头，没有验证楼层数量和几何。
2. V1：70页Manual、Word说明、36款SVG、9表BOQ以及结构化project_data。完整原包位于`inputs/v1/`，不覆盖。
3. 原施工参考：26页《全厂目视化设计与施工方案》，用于追溯楼层功能和原规则，不把其中待复核参数当成批准工程条件。
4. 原2025样册在本轮运行环境中无法取回完整字节，不包含在项目包；不因此新造Logo、历史和数据。
5. Taste：官方指定来源，只借鉴符合工厂情境的审查和排版方法。

## 分工

Codex做可重复工作：资料清点、文件转换调用、模板生成、点位数据校验、图层叠加、清单汇总、批量输出和视觉检查。设计负责人审美与体系；生产负责操作与物流；品质负责状态与放行；工程负责设备/工装/模具及安装；安全负责人负责专项边界；销售负责对客展示；业主做关键决策。

项目不赋予Codex改变疏散、消防、承重、防爆、电池应急处置或安全审批的权力。不得为审美重画建筑墙体、移电梯或改变设备实际位置。

## 首批范围

P01/P02形成可校核底图；P03审查全部模板；P04只深化六款高频模板；P05做8F真实点位草案；P06人工确认后复制到其他楼层。先处理真实工作流，不先造大厅英雄图和满屏营销口号。
