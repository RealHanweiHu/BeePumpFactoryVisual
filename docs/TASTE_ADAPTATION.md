# Taste → BeePump 的适用规则

## 实际来源及选择

上游：Leonxlnx/taste-skill。锁定commit：`ce26fc25c0e5e8cab638f883de62d9a86ee5e45b`（读取日期2026-10-04）。本包附官方 `redesign-existing-projects` 的原文和MIT许可；SHA校验用于确认原文未改。主skill的公开开头明确其重点为landing pages、portfolios、redesigns，并非dashboards/data tables，因此不能把默认8/6/4或网页栈直接当作工厂规范。

本包专用skill不是Taste官方的“工业版”；它是本项目的适用范围说明。也不同时堆叠gpt-tasteskill、soft-skill等互相冲突的默认风格。

## 采用

先读受众/业务/现有品牌；先渲染再审查；保留功能做定向改进；用字号、对齐、空间建立主次；数字对齐；压低无意义装饰；交付前检查缺字、溢出、状态语义和可更新性。预览界面有真实空状态、焦点、错误提示，不做假Dashboard。

## 必须覆盖或排除

| 上游网页建议 | 工厂项目处理 |
|---|---|
| 改纯黑背景、降低所有强调色饱和度 | 不改已指定#000000和#FF6600；调整面积与层级，不私改色号 |
| 只有一个accent | 仅指品牌色；质量/安全语义保持独立，不删红黄绿蓝 |
| 替换假整数字为更像真的数字、随机日期 | 完全禁止；使用真实值、待填或明确的样例标签 |
| 非对称布局、错位、层叠、动画、玻璃效果、纹理 | 不用于物理牌、SOP、地面与安全信息；工具界面也保持稳定 |
| 添加placeholder实景照片 | 不作为本厂现状；只有用户实景才能证明现场条件 |
| 统一浅色或深色主题 | 品牌空间黑底、作业白底是明确功能分层，不被当作错误修掉 |
| 图标全部换库 | 安全图形只用专项批准的标准素材；品牌图标非必要不加 |
| 字号使用px/rem | 物理模板记录mm和实际字高；网页预览尺寸不等于成品尺寸 |

## V2逐项审查字段

模板编号；原文件；原目标；需保留内容；问题位置；Preserve/Refine/Retire；理由；变更后文件；输出尺寸；远/近阅读优先级；版本；截图证据；内容确认；专项确认。

不得按“删掉70%蜂窝”等口号硬删：逐个元素证明是否有识别作用。数字编号是功能；蜂巢是次要品牌元素，不能替代方向或状态。
